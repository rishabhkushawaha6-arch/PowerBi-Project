# 📱 Mobile Sales Dashboard | Power BI

## 📌 Project Overview
This project presents an interactive Mobile Sales Dashboard developed using Microsoft Power BI. It helps analyze mobile sales performance across different brands, models, cities, months, payment methods, and customer ratings.

## 🎯 Project Objectives
- Analyze total sales and quantity sold.
- Track transactions and average selling price.
- Compare sales across mobile brands and models.
- Understand monthly and daily sales trends.
- Analyze customer ratings and payment methods.
- Explore city-wise sales performance.

## 📊 Dashboard Highlights
- **Total Sales:** 769.2M
- **Total Quantity Sold:** 19,150
- **Total Transactions:** 3,835
- **Average Price:** 40.11K

*Note: Figures are based on the displayed dashboard and should be verified against the source dataset.*

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Microsoft Excel / CSV Dataset
- Data Cleaning and Transformation
- Data Visualization
- Interactive Slicers and Filters

## 📈 Key Features
- Interactive filters for mobile model, brand, city, payment method, and month.
- KPI cards for key sales metrics.
- Monthly quantity trend analysis.
- City-wise sales map.
- Brand-wise sales and quantity table.
- Customer rating distribution.
- Payment method analysis.
- Mobile model and day-wise sales comparisons.
